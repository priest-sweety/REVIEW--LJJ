# REF03 — A conserved re-epithelialization program underlies malignancy in pancreatic ductal adenocarcinoma

- **Citation / DOI:** Zhuo M, Li Y, Zhang Y et al. (2026). *Cancer Cell*. DOI: [10.1016/j.ccell.2026.03.021](https://doi.org/10.1016/j.ccell.2026.03.021)
- **Article type & disease stage:** Original Research · PanIN-to-PDAC Transition
- **Public datasets / code accessions:** `HRA005010;GSE248586;EGAS00001006661`
- **Mapped review sections:** `1.3 PanIN; 1.4 PDAC; 2. Immune Reprogramming; 3. Therapeutic Windows`
- **Assays and study design:** Multi-cohort scRNA-seq meta-programs (MP10/MP11/MP4/MP5), spatial transcriptomics, ChIP/epigenomics, and functional genetic perturbation
- **Key findings for pancreatic inflammatory niche synthesis:** Identifies FOSL1-driven cutaneous-like re-epithelialization program (MP10: LAMC2/ITGB4/F3, distinct from canonical EMT) restrained in <4% low-grade PanIN cells until CDKN2A/TP53 loss, amplified by wound-like CTHRC1high myCAFs (MP4) via EGFR signaling.
- **Limitations / transferability notes:** Provides a targetable CTHRC1high myCAF -> neoplastic EGFR -> FOSL1 -> MP10 invasion circuit bridging precancerous PanIN and invasive PDAC.
