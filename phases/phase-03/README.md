## Purpose

Which intercellular signaling axes reprogram innate and adaptive immunity from tissue repair toward chronic fibroinflammation and tumor immune evasion?

- **Primary working hypothesis / synthesis thesis:** Reciprocal circuits linking injured/neoplastic epithelium (SPHK1/S1P, ICAM-1, IL-6, FOSL1), heterogeneous PSCs/CAFs (IL-33, C3, CTHRC1-EGFR, PLXDC1, CCL19), plastic myeloid subsets (SPP1+/NLRP3+ TAMs, CXCR2/NETs), T cell subsets (CCR6-CCL20, FOXP3+ Treg), and TGFBI+ Schwann cells drive niche evolution.
